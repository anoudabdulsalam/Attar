# 🌸 Attar

**Attar** is a perfume marketplace application that connects customers, shop owners, and perfume experts through a modern and user-friendly platform. The application provides an easy shopping experience, personalized recommendations, and communication features, making it easier to discover and purchase perfumes.

---

## 📱 Features

### 👤 Customer
- User registration and login
- Browse perfumes and categories
- Search by name
- Image-based product search
- View product details
- Add products to favorites
- Shopping cart management
- Secure checkout process
- Order tracking
- Chat with shop owners and experts
- Receive push notifications
- Manage personal profile
- AI chat

### 🏪 Shop Owner
- Manage perfume products
- Add, edit, and delete herbs
- View and manage customer orders
- Chat with customers
- Receive notifications
- Manage profile information

### 🌸 Perfume Expert
- Communicate with users
- Share recommendations
- Manage profile information
- Receive notifications
- Chat with customers and shop owners
